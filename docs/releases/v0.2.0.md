# Runpod Weld 0.2.0 — Linux amd64

Weld builds trusted Dockerfiles into OCI images on ordinary Linux Pods without
a Docker daemon. Its supported Dockerfile subset and kernel requirements remain
documented in the README; it is not a security sandbox.

## Changes since 0.1.0

- Incremental layered checkpoints preserve completed instruction cache entries.
  Managed builds retain bounded verification evidence for owned payloads and
  reuse it across eligible checkpoint publication and inheritance operations.
- Managed COPY checkpoints reuse unchanged regular-file hashes using recorded
  COPY writes. RUN, unsupported mutations and resource limits retain full
  verification or conservative fallback. Public callback APIs remain conservative.
- Optional deterministic gzip export compresses newly generated layers. Raw
  layers remain the default; inherited descriptors are preserved.
- Bounded RUN secret and persistent package-cache mounts support the documented
  profile, including image-target restoration and cache ownership protection.
- Offline packaging handles restrictive umasks and verifies exact installed
  payloads. The validator accepts literal backslashes in Linux layer names while
  retaining path traversal protection.

The accepted synthetic 1 GiB Pod comparison measured 32.4% lower cold-build time
and 8.5% lower application-edit time for the COPY checkpoint change. Warm and
no-cache controls were essentially unchanged. These are workload-specific
measurements, not a general large-image throughput guarantee. See
[the measurements](../copy-checkpoint-performance.md).

## Install

Verify the downloaded files against `SHA256SUMS`, then install
`rpweld_0.2.0_amd64.deb` with `sudo dpkg -i rpweld_0.2.0_amd64.deb`, or extract
`rpweld-0.2.0-linux-amd64.tar.gz` and run its `bin/rpweld`. Keep the portable
`bin`, `lib` and `share` directories together. Run `rpweld doctor` on the target.

The Weld binary is static; the full package also carries Skopeo, its loader and
shared-library closure, CA certificates, notices and corresponding source.
Installation does not download dependencies or replace host Skopeo/libraries.
Existing signature policy and CA overrides retain precedence. Bundled components
are updated by installing a new Weld package, not by host package upgrades.

## Limits

Linux amd64 only. RUN uses the host kernel and requires the documented native
filesystem permissions and capabilities. Secrets are materialized as private
ordinary files; fatal termination can leave private work residue, and trusted RUN
commands can deliberately disclose them. Consult [the mount profile](../run-mounts.md).

Full Docker/BuildKit compatibility, GPU inference certification and performance
guarantees are outside this release. The release's validation report records
the exact tested artifacts and remaining limitations. Earlier incomplete
Nemotron trials are not acceptance evidence for this release.

Weld is Apache-2.0. Dependencies retain their licenses. `build-info.json` records
the exact source revision, build tools and bundled payload hashes; release assets
include matching sources and `SHA256SUMS`.
